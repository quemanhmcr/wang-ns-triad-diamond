# Material-native joint-stop projection

Status: **DRAFT THEOREM CANDIDATE — independent PR, not certified, not merge-ready.**

The native material-service factorization says that OO/ON/NN and selected-family data are restrictions/sidecars on an already-existing physical law. The event topology must now obey that ontology.

The certified `joint_stop_master_projection` core is deliberately left unchanged. This draft adds an opt-in wrapper with one rule:

\[
\boxed{\text{first classify physical/internal stops; attach material provenance only afterward}.}
\]

## 1. Legacy material roots fail closed

The new wrapper refuses stand-alone `PhysicalCause.MATERIAL_RELINK` and `PhysicalCause.NEW_COHERENT_ANCESTRY`. A caller using the native factorization must instead supply the independently witnessed PDE cause: actual source/service, strain/dissipation, physical work, or the already-bound HH internal route. Material interface/freshness remains provenance on that same law.

This is not a rewrite of the certified legacy API. It is a stricter candidate interface for the reduced architecture.

## 2. Material-only observation is not a stop

If an observation contains only membership rereading, selected-family Moyal boundary currency, OO/ON/NN restriction of an already-existing law, or same-event smooth `K_phys` relay, and no independently witnessed physical/internal stop is present, the wrapper returns **no causal stop**.

It does not pass `kelvin_flat_certified=True`: absence of a material cause is not a theorem that the carrier is Kelvin-flat. It simply says the material observation did not create an event vertex.

## 3. Exact native ties are preserved

When real native hits are present, the wrapper calls the existing certified core without inserting any material `CauseHit`. Thus source/strain/HH and every other native exact tie remains the same unsplit joint set, with the same first time and disposition. Material data are attached afterward and cannot join the tie.

This is the topology needed for the mixed-owner reduction. A material label can no longer manufacture an epoch breaker between two events already governed by the same native recurrence law.

## Scope

This candidate closes only the event-topology consequence of native material factorization. It does not yet telescope the surviving HH/high-tail, strain/dissipation, objective source/service, and causal-reuse families. It makes no Navier--Stokes global-regularity claim.
