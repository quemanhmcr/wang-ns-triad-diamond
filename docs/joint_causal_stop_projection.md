# Joint causal stops: exact simultaneity is a physical set, not a fraction problem

The single-charge compiler originally resolved an exact first-time tie between
independent causal roots by a Radon--Nikodym split.  That is a legitimate fine
bookkeeping device **when** all causes already supply positive weights against a
common physical measure.  It is not, however, necessary for the global master.

More importantly, requiring such a common weight can create an artificial PDE
bridge: source work, strain action, Moyal relink energy and a dimensionless
threshold excess are not quantities nature asks us to normalize against each
other.

The better object is the **joint physical stop**.

## 1. Keep exact simultaneous provenance intact

Let

\[
J=\{r:\tau_r=\tau_*\}
\]

be the set of physical causal roots which first hit at the same physical time.
If an earlier high--high generation clock also hits there, include it in the
joint recursive provenance.

Do not split the event measure.  The entire event/block still carries one unit of
its physical transfer mass.  The information retained is simply the finite set
`J`.

This is more faithful to the PDE: simultaneous source and strain can genuinely
occur at the same spacetime event, and there need not be a physically meaningful
number saying that the event is “42 percent source”.

## 2. The master sees terminal semantics, not theorem names

Every fine physical currency already maps to one coarse master disposition.
This induces a natural logic on a joint stop.

### Initial boundary

If `t=0` is in the first joint set, it is absorbing:

\[
\boxed{J\ni t=0\Longrightarrow\text{BOUNDARY}.}
\]

No negative-time or fresh-interior route survives.

### Fixed multiplicative cost

If any simultaneous cause already certifies a fixed multiplicative
transfer/reuse/sideband cost, then the whole joint state satisfies that terminal
certificate.  Nothing is gained by recursively charging another simultaneous
cause:

\[
\boxed{
J\cap\mathcal C_{transfer}\ne\varnothing
\Longrightarrow\text{TRANSFER COST}.
}
\]

This is not a causal priority.  It is logical implication: a terminal cost is
already true on that state.

### Genuine global reset

If there is no transfer certificate but the joint state contains a resource with
a proved scale-independent threshold in a genuinely globally bounded resource,
then it may terminate as the existing additive reset.  Critical `NE` and `D_V`
do not qualify.

### Recursive joint stop

All remaining simultaneous causes are recursive:

\[
\boxed{
\text{source / SGS}
\cup
\text{critical dissipation}
\cup
\text{material/new ancestry}
\cup
\text{earlier HH generation}
\Longrightarrow
\text{RECURSE}.
}
\]

Their relative fractions are immaterial to the master because **every one of
them remains inside the same recursive class**.

## 3. Why this removes the tie-weight bridge

Take any exact joint cause set and attach arbitrary positive dummy weights
`a_r`.  Change them to completely different positive numbers `b_r`.  The joint
physical provenance is unchanged, and so is the coarse master disposition.

Thus

\[
\boxed{
\text{preferred master projection is invariant under all positive tie weights}.
}
\]

A fine Radon--Nikodym partition is optional metadata, not a hypothesis of the
Navier--Stokes no-escape mechanism.

This distinction matters.  The physical proof must construct which causes occur
and when.  It does **not** need to invent a common unit for causes whose
observables have intrinsically different units.

## 4. Single charge is preserved more literally

Under a fractional tie split,

\[
d\mathcal T_J=\sum_{r\in J}\lambda_r d\mathcal T_J.
\]

Under the joint-stop formulation there is no such auxiliary decomposition:

\[
\boxed{d\mathcal T_J\text{ remains }d\mathcal T_J.}
\]

The master attaches one disposition to it.  The complete set of fine physical
causes remains as provenance and may be inspected by downstream diagnostics, but
none receives a second copy of the transfer mass.

This is arguably the strongest possible meaning of **single charge**.

## 5. Relation to the generated first-stop constructor

The generated physical-work constructor has three outcomes:

- terminal physical cause;
- earlier HH regeneration;
- registered continuation.

If a physical cause and HH regeneration tie exactly, the joint-stop theorem says
that no RN split is needed.  If the physical cause is terminal transfer, the
joint state is terminal.  Otherwise both are recursive and the whole event stays
inside one coarse recursive class.

The survivor fraction `q` is therefore simply the measure of events with **no
first joint stop** before successful registration.  Its productivity remains
`q Lambda` exactly as in the physical KL theorem.

## 6. New frontier

The old remaining task was phrased as “construct common-unit RN stopping
densities on positive-measure exact tie sets.”  That task is no longer required
for the master.

The continuum question is now cleaner:

> For every recursively selected smooth-SGS block, construct the measurable
> first-hit **set of physical causes** from the actual Navier--Stokes observables,
> and show that the no-hit set is precisely the registered survivor set used by
> physical pair productivity / Kelvin-flat continuation.

This is a stopping-time / witness-extraction problem, not a measure-conversion
problem.  No global-regularity claim is made.
