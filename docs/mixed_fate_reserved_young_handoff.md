## 1. Exact hard-cell Hahn bookkeeping

Fix one deterministic hard product cell `C`. Define the four actual pushforward masses

\[
\begin{aligned}
g_C&=(\pi_\#dW_G^+)(C),\\
b_C&=(\pi_\#dW_B^+)(C),\\
n_C&=(\pi_\#dW^-)(C),\\
T_C&=(\pi_\#dW)(C).
\end{aligned}
\]

Because the Hahn decomposition was performed once, on edge space, linear pushforward gives the exact identity

\[
\boxed{T_C=g_C+b_C-n_C.}
\]

The hard-cell compression carries all three linear pushforwards directly: `pi_#dW`, `pi_#dW^+`, and `pi_#dW^-`. In particular, `n_C` is accumulated from the original negative edge masses before hard aggregation. The exact identity

\[
\boxed{n_C=(g_C+b_C)-T_C}

remains a theorem check, but it is **not** used numerically to manufacture `n_C` by subtracting nearly cancelling aggregates. This preserves tiny canonical negative work and is still not a later Hahn split.

Every term has the units of physical child-energy work. Parent exchange, helicity basis gauge, and the continuum parent quotient have already been removed before these masses are formed, so this identity inherits those symmetries.

## 2. The reservation identity

Let `Y_C>0` be a separately certified sharp full-cell Young upper for the actual hard roles and actual weighted trilinear form, so

\[
|T_C|\le Y_C.
\]

For example, after symbol freezing this is the same `m_* A_3` times the three physical `L^{3/2}` role norms which enters the existing complex Young theorem. It is not the native modal capacity `dA` and it is not a causal law.

Define only as a scalar certificate

\[
U_C:=T_C-b_C=g_C-n_C.
\]

Then define

\[
\delta_C^{\rm full}:=1-\frac{T_C}{Y_C},\qquad
\alpha_C^{\rm bad}:=\frac{b_C}{Y_C},\qquad
\delta_C^{\rm res}:=1-\frac{U_C}{Y_C}.
\]

There is an exact identity

\[
\boxed{
\delta_C^{\rm res}
=\delta_C^{\rm full}+\alpha_C^{\rm bad}.
}
\]

This is the central observation. The reserved deficit is exactly the ordinary full signed Young deficit plus the normalized contribution which the already-terminal bad-positive sublaw can make to that cell.

### What `U_C` is not

`U_C` is **not** a physical trilinear form. The map `dW -> dW_B^+` contains a Hahn-positive operation and hence is nonlinear in the underlying field. Already in one scalar bad edge,

\[

\]

Therefore no theorem downstream is permitted to feed `U_C` to Young, Christ, Duhamel, or a new causal compiler. It is only a sufficient-condition inequality involving two already-certified measures.

## 8. What this theorem closes, and the new frontier

For every full-signed Young/Christ-good cell define the spare margin

\[

\]

\[

\[

of the canonical good work. This is an actual-work statement. Failed good work is not relabelled terminal; locally it is dominated by canonical negative work plus already-terminal bad-positive work.

The local frontier is therefore sharper:

1. full-signed cells whose Christ margin degenerates toward zero;
2. the canonical negative-work/cancellation term which dominates the remaining nondegenerate-margin failures and now needs its own native recurrence telescope without double charge;
3. a separately proved positive kernel, if later coherent/material representations require one—never fresh coherent Hahn.

This theorem does not prove generic HH termination, mixed genuine-owner recurrence, initial-data closure, a singular-time interface, or Navier--Stokes global regularity.
