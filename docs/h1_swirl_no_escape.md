# Mild-aspect `H1`/swirl local no-escape theorem

On the branch

\[
\operatorname{cond}L(t)\le21/20
\quad(0\le t\le T),
\]

the physical `H1` bridge gives a transfer-facing relative-parent/child sideband forcing with

\[
\boxed{
\|f_{H1}^{rel}(t)\|_2^2
\ge\frac1{50}\|B^H(t)\|_F^2.
}
\]

Put

\[
I_1=\int_0^T\|B^H(t)\|_Fdt.
\]

Measure the forcing in the fully pulled-back relative-helicity interaction frame, so common parent `SL(2)`, carrier/frame gauge and base spinor propagation are removed before differentiating.  The Banach/Hilbert interval-variation theorem gives

\[
\boxed{
J_1\ge\frac{I_1}{\sqrt{50}T}
}
\]

for the covariant forcing variation `J1`, or a first-Duhamel `H1` daughter

\[
\boxed{\delta_1^2\ge\frac1{200}I_1^2.}
\]

If nonlinear sideband feedback cancels at least half of `delta1`, it is already a high--high sideband interaction branch.  Otherwise

\[
\delta^2\ge I_1^2/800.
\]

For degree one the critical `|G|^(3/2)` Gaussian has variance `4/3`, so its second moment is larger than the `L2` second moment.  If the critical sideband parameter reaches `1/80`, there is a definite daughter-capacity event.  Below that threshold, odd-Hermite uniform convexity gives single-role transfer loss at least `sigma^2/16`.  Splitting against possible pair rescue gives

\[
\boxed{
\operatorname{Def}_{transfer}\ge\frac1{25600}I_1^2
\quad\text{or}\quad
R_{pair}\ge\frac1{25600}I_1^2.
}
\]

The pair branch is already routed by the odd-sideband ancestry graph into `Xi`, dominant reuse, Bellman entropy or same-ancestry cycles.

There is also a clean full-curvature consequence.  The irreducible split satisfies

\[
\|B\|\le\|B^E\|+\|B^H\|
\le\sqrt6\|\operatorname{Sym}B\|+\|B^H\|.
\]

After integrating,

\[
I_B\le\sqrt6 I_3+I_1.
\]

Therefore either

\[
I_3\ge I_B/(2\sqrt6)
\]

or

\[
I_1\ge I_B/2.
\]

The H3 local cost on the first branch is at least `I_B^2/32768`; the H1 cost on the second branch is at least `I_B^2/102400`.  Hence the common clean constant is

\[
\boxed{c_{mild,curv}=1/102400.}
\]

This is **not** yet a complete physical H1 source theorem. Grains leaving `cond(L)<=21/20` are not assigned an aspect defect; they pass to the affine fresh/reuse ancestry branch.
