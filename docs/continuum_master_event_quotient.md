## 1. Why the apparent recursion was too large

The current continuum architecture has many certified maps

`source -> owner -> service/tail/pair -> hard shell -> first-stop corridor`.

It is tempting to regard every arrow as a new recursive generation.  That is not
physical.  Several arrows are only pushforwards, restrictions, or certified consequence maps from an already existing positive physical law to a downstream state observable.  A source compiler does not create
a second source by naming its SGS owner; a pressure-pair theorem does not create a
second pressure law by exposing the hard shell already carrying that pair; a fresh

Exact ties remain a set of owners of the same unsplit event.
