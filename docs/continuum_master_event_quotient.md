## 1. Why the apparent recursion was too large

The current continuum architecture has many certified maps

`source -> owner -> service/tail/pair -> hard shell -> first-stop corridor`.

It is tempting to regard every arrow as a new recursive generation.  That is not
physical.  Several arrows are only pushforwards, restrictions, or certified consequence maps from an already existing positive physical law to a downstream state observable.  A source compiler does not create
a second source by naming its SGS owner; a pressure-pair theorem does not create a
second pressure law by exposing the hard shell already carrying that pair; a fresh
service scale pushforward does not create a new causal probability by recording
its LP band.

The master must therefore quotient **relay depth** before counting recursion.
A same-law zero-charge relay may add downstream provenance while the underlying physical measure occurs once.  A more general witness relay may change units---for example source work to shell critical mass---but it creates a state consequence, not a second independent causal charge.  Exact ties remain a set of owners of the same unsplit event.
No theorem-name priority and no heterogeneous tie normalization is introduced.

This quotient is the continuum counterpart of the already certified affine,
cutoff, material-label and exact-tie quotients.

\[
