# Strictly descending fresh-SGS scale epochs are finite

Status: **DRAFT THEOREM CANDIDATE — independent PR, not certified, not merge-ready.**

After closing all resolved pressure-pair epochs, the difficult objective-source survivor is the fresh SGS service route. Its canonical scale theorem intentionally gives no global direction: the selected hard child can lie as high as `2N`.

There is nevertheless a genuine subepoch which the existing local laws already close: **fresh renewals whose selected physical child satisfies `N_next<=N/2`.**

## 1. Fresh positive service has a local square-frame envelope

The canonical annular frame is square-normalized:

\[
\sum_j\phi_j(\xi)^2=1,
\qquad
u_j=\phi_j(D)u,
\qquad M_j=2^jN.
\]

For each fresh band, the certified Moyal/increment estimate gives

\[
F_j\le4\int M_j\|u_j\|_2^2\,d\tau.
\]

On the low/base fresh route `j<=0`, hence `M_j<=N`. Summing and using square normalization,

\[
\begin{aligned}
F_{fresh}
&=\sum_{j\le0}F_j\\
&\le4N\int\sum_{j\le0}\|u_j\|_2^2d\tau\\
&\le4N\int\|u\|_2^2d\tau\\
&\le4cNE_{global}.
\end{aligned}
\]

The actual fresh owner carries

\[
F_{fresh}\ge Y/4.
\]

Therefore every such fresh-source parent satisfies

\[
\boxed{
N\ge N_{min}^{fresh}:=\frac{Y}{16cE_{global}}.
}
\]

Again this is not an additive budget. The service is actual positive service; the square-frame estimate is only its local upper envelope on one event.

If SGS is a qualifying objective owner,

\[
\Sigma_R\ge\frac{A_*}{4c},
\qquad
Y\ge C_Y\Sigma_R,
\qquad
C_Y=\frac{380}{g_1(1+g_1)(C_{LP}C_B)^2},
\]

so

\[
\boxed{
N\ge
\frac{C_YA_*}{64c^2E_{global}}.
}
\]

## 2. The descending subepoch

The fresh scale theorem selects a canonical LP band `j_*<=0`, with `M_*=2^{j_*}N`, and then one of the two actual hard shells

\[
M_*,\qquad 2M_*.
\]

Whenever the physical selection satisfies

\[
\boxed{N_{next}\le N/2,}
\]

we obtain supplier-specific descent. In particular, every `j_*<=-2` selection has this property; the lower shell at `j_*=-1` does as well.

For `L` consecutive descending fresh-SGS events,

\[
N_j\le2^{-j}N_0,
\qquad
N_j\ge N_{min}^{fresh}.
\]

Hence

\[
\boxed{
L\le
1+\left\lfloor
\log_2\left(\frac{N_0}{N_{min}^{fresh}}\right)
\right\rfloor.
}
\]

No generic `A=3M/4` carrier registration enters this count.

## 3. What survives

A non-descending fresh renewal can only come from the top canonical LP geometry:

- `j_*=0`, whose two hard candidates are `N` and `2N`;
- `j_*=-1`, whose candidates are `N/2` and `N`, with the upper choice non-descending.

Those events are **not** declared costs, resets, or fake material relinks. Fresh scale `H_inf/H2` remains deterministic service-scale concentration only, and NN provenance is not promoted to whole-shell freshness.

Thus the unresolved eventually-pure fresh-SGS problem has been sharpened to:

> can actual positive fresh SGS service renew indefinitely while repeatedly selecting only top/comparable LP shells, without falling into high-tail work, dissipation, interface `Xi`, reservoir reuse, or another native owner?

That is a much smaller and more physical question than arbitrary fresh-scale recurrence.

## 4. No event-gap shortcut

The source action is a first-hit observable inside the natural corridor. The current theorems do not provide a scale-independent minimum physical time gap between successive source first stops. This telescope therefore uses no assumed `cN^{-2}` event spacing. The finite count comes only from a local service/energy parent floor plus actual half-scale descent.
