# Recursive physical witness constructor: first-stop survival on actual HH work

After outer-role extraction, event registration and physical pair-weighted
productivity, the generated branch can be written entirely on one conserved
object: **actual positive high--high child-energy work**.

This note separates what is now exact from the one local continuum task which is
still missing.

\[

## 2. Three destinations and no fourth one

For an event `omega`, inspect only causal data which occurred no later than its
common-slice registration interval.

After quotienting duplicate manifestations of one cause, exactly three kinds of
destination are admissible:

1. **physical first stop**: transfer loss, source/SGS, strain/critical
   dissipation, material relink/new ancestry, reuse, sideband, a genuine uniform
   global resource, or `t=0`; these are the currencies of the existing branch
   compiler;
2. **earlier HH regeneration**: the adjoint first-stop gate found a genuine
   high--high generation before the proposed common slice, so the event is
   recursively re-entered at that earlier physical generation rather than
   charged as a new currency;
3. **registered continuation**: the event is complex-Young/phase good and both
   parent coefficients survive the common-slice first-stop gate.

A Young/phase-bad event is not allowed to become an unmarked survivor.  Its
physical transfer deficit is the first-stop witness.  A failed registration is
not allowed to become packet “decoherence”: it must carry source/relink or
HH-regeneration provenance.

Let `tau_r(omega)` be the first physical time of a certified cause and

\[
\tau(\omega)=\min\{\tau_r(\omega),\tau_{HH}(\omega)\}.

\[

\]

law `dT|C/(qW)`.  The child energy bound still uses the full generated work `W`,
while the retained density numerator is `qW`.  Therefore

\[
\boxed{\Lambda_{surv}=q\Lambda_{full}.}
\]

This gives a particularly clean causal alternative:

\[
\boxed{

\quad\Longrightarrow\quad
\text{more than half of current physical HH work has already stopped or regenerated},

\[
\boxed{

Thus forcing every event to be good was unnecessary.  The natural quantity is
survival probability under physical work.
