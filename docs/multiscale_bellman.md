# Transfer-weighted multiscale Bellman inequality

This module is an abstract finite-resolution theorem, not a proof of
Navier--Stokes regularity.

Let parent interaction components have critical `p=3/2` masses
`X_v,Y_v,Z_v`, normalized to sum one on each side.  Put

\[
S=\sum_v (X_vY_vZ_v)^{2/3},\qquad
\lambda_v=\frac{(X_vY_vZ_v)^{2/3}}{S}.
\]

Inside parent `v`, let `alpha^X_{v,i}`, `alpha^Y_{v,i}` and
`alpha^Z_{v,i}` be conditional child masses. Define collision factors

\[
c_X(v)=\sum_i(\alpha^X_{v,i})^2
\]

and similarly for `Y,Z`.  The local Bellman score satisfies

\[
s_v=\sum_i(\alpha^X_{v,i}\alpha^Y_{v,i}\alpha^Z_{v,i})^{2/3}
\le [c_X(v)c_Y(v)c_Z(v)]^{1/3}.
\]

If `rho_v in [0,1]` is a local loss caused by reuse/holonomy, then the
refined-to-parent transfer ratio is bounded by

\[
R\le \sum_v\lambda_v\rho_vs_v.
\]

Set `g_v=(c_Xc_Yc_Z)^{1/3}` and

\[
\bar\rho=\frac{\sum_v\lambda_v\rho_vg_v}
{\sum_v\lambda_vg_v}.
\]

Two applications of Holder give the exact block estimate

\[
R\le \bar\rho
\prod_{A\in\{X,Y,Z\}}
\left(\sum_v\lambda_vc_A(v)\right)^{1/3}.
\]

Hence

\[
-\log R\ge
\frac13\sum_A
\left[-\log\sum_v\lambda_vc_A(v)\right]
-\log\bar\rho.
\]

The first term is a **transfer-weighted conditional collision entropy**.
Unlike ordinary Renyi entropy, its weights are generated by the parent
transfer itself.  This makes the estimate telescope exactly when block
ratios are multiplied through scales.

## Cross errors

If omitted cross-component interactions contribute `eta_j`, then

\[
R_j\le A_j+\eta_j,
\qquad
-\log R_j\ge -\log A_j-\log(1+\eta_j/A_j).
\]

Thus a summable relative error `sum eta_j/A_j < infinity` does not destroy
additivity.

## Holonomy convex certificate

Suppose local single-edge stability yields

\[
d\ge A|s|+Bt^2
\]

and a reuse motif imposes the exact log-scale relation `s+t=gamma_*`.
Then the least possible block cost is

\[
\kappa(A,B,\gamma_*)=
\begin{cases}
B\gamma_*^2,&2B\gamma_*\le A,\\
A\gamma_*-A^2/(4B),&2B\gamma_*>A.
\end{cases}
\]

This is a soft-thresholding calculation and is exact.  What remains to be
certified for the Navier--Stokes multiplier is a global/local stability
pair `(A,B)`.

## Abstract no-escape corollary

If every block has either conditional collision entropy at least `h0` or
reuse cost at least `k0`, then a depth `L` cascade has efficiency at most

\[
\exp[-L\min(h_0/3,k_0)]
\]

up to the summable cross-error correction.  Therefore an infinite cascade
with uniformly nonvanishing efficiency would have to make *both* defects
go to zero.  The grain inverse theorem and scale holonomy are designed to
show those two requirements are incompatible.
