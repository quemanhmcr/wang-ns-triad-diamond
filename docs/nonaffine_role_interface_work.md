# Nonaffine hard-projector role-interface work: conservative relinking plus physical strain

The exact outer-role theorem leaves one operator term

\[
R_Q=(\partial_tQ+[\mathcal L_V,Q])u.
\]

After the scalar role is transported by the coherent affine dual flow, the common
affine contribution is identically zero.  The remaining operator is the
non-affine part of resolved linearized transport.  This note identifies the
corresponding energy algebra exactly on a complete orthogonal **hard event-role
partition**.  The propagated PDE envelope is smooth and non-idempotent; its
separate `Q^2` energy handoff is supplied by
`smooth_quadratic_carrier_interface.md`.

## 1. Adjoint split of resolved linearized transport

On the divergence-free `L^2` space, write the non-affine resolved linearized
operator as

\[
\boxed{\mathcal L_{na}=K+S},
\qquad
K^*=-K,
\qquad
S^*=S.
\]

For incompressible residual velocity `r`, formally

\[
K=\mathbb P(r\cdot\nabla+\Omega_r),
\qquad
S=\mathbb P S_r,
\]

where

\[
S_r=\operatorname{sym}\nabla r,
\qquad
\Omega_r=\operatorname{skew}\nabla r.
\]

The decomposition is just integration by parts: divergence-free advection is
skew-adjoint, vorticity rotation is skew, and symmetric deformation is the
self-adjoint energy-changing part.

## 2. Binary role/complement identity

Let `Q` be an orthogonal outer-role projector and put

\[
z=Qu,
\qquad
y=(I-Q)u.
\]

The interface work generated by an operator `L` is

\[
\mathcal I_Q(L)
=2\Re\langle Qu,[L,Q]u\rangle.
\]

For the skew part,

\[
\boxed{
\mathcal I_Q(K)
=-2\Re\langle z,Ky\rangle,
}
\]

while the complementary role obeys

\[
\boxed{
\mathcal I_{I-Q}(K)=-\mathcal I_Q(K).
}
\]

Thus this is exact **role-to-role transfer**.  It cannot create energy.

For the symmetric part,

\[
\boxed{
\mathcal I_Q(S)
=-2\Re\langle z,Sy\rangle,
}
\]

and

\[
\boxed{
\mathcal I_{I-Q}(S)=\mathcal I_Q(S).
}
\]

This is the off-diagonal physical strain work between the two role subspaces.

## 3. Complete outer-role partition

Let

\[
I=\sum_aQ_a,
\qquad Q_aQ_b=0\quad(a\ne b),
\qquad w_a=Q_au.
\]

For the skew operator define pair fluxes

\[
\boxed{
T_{ab}=-2\Re\langle w_a,Kw_b\rangle.
}
\]

Then

\[
\boxed{T_{ab}=-T_{ba}},
\]

and

\[
\boxed{
\mathcal I_a(K)=\sum_bT_{ab},
\qquad
\sum_a\mathcal I_a(K)=0.
}
\]

So the entire non-affine advection/rotation part of the moving-role interface is
an antisymmetric physical flux on the role graph.  It is redistribution/relinking,
not generation.

For the symmetric part define

\[
\boxed{
D_{ab}=-2\Re\langle w_a,Sw_b\rangle.
}
\]

Then

\[
D_{ab}=D_{ba}
\]

and

\[
\mathcal I_a(S)=\sum_bD_{ab}.
\]

Most importantly,

\[
\boxed{
\sum_a\mathcal I_a(S)
=
2\sum_a\Re\langle w_a,Sw_a\rangle
-2\Re\langle u,Su\rangle.
}
\]

Hence the symmetric interface is exactly the missing off-diagonal piece needed
to reconstruct the **same full physical strain work** from the diagonal role
strain works.  It is not an independent source.

## 4. Single-charge interpretation

This gives the physical quotient of the Heisenberg term:

\[
\boxed{
\text{non-affine interface}
=
\text{conservative role flux}
+
\text{off-diagonal strain work}.
}
\]

The two destinations already exist:

- conservative role flux is a physical role switch/relink/redistribution event;
  if the same material ancestry is retained it is not new generation;
- symmetric cross work has the same provenance as resolved strain/coherent
  deformation.  Its large branch is handled by the existing `K_coh`, objective
  source and critical-`D_V` theorems; its small branch is part of the already
  certified coherent connection flatness.

Therefore a moving-projector commutator is **not** allowed to create another
currency merely because it is written with brackets.  Nor may it be called
representation `Xi`: both pieces are physical work.

## 5. Relation to the exact outer-role equation

The companion outer-role theorem gives, for a smooth envelope,

\[
(\partial_t+\mathcal L_V-\nu\Delta)w
=-Q\mathbb P\nabla\cdot(h\otimes h)+R_Q.
\]

The first term is true quadratic high--high generation.  If `Q` is itself an
orthogonal hard projector, the present theorem says that the second has no
independent generation content:

1. its skew piece only moves existing role energy;
2. its symmetric piece is already the resolved deformation work.

For the actual non-idempotent PDE envelope one must not make that substitution.
The physical carrier energy is `<u,Q^2u>`.  The smooth quadratic-carrier theorem
proves directly that the native interface work equals the work of `R_Q` minus
the diagonal `L_V` work of `Q u`; on a complete square partition its skew part
is conservative relink and its symmetric part is the same resolved strain.

## 6. Remaining scope

The orthogonal hard-role algebraic identity is closed.  The smooth-envelope
handoff is a distinct theorem because `Q^2` is the energy effect and `I-Q` is not
the energy complement of a non-idempotent `Q`.  Quantitative eventwise stopping
still uses actual physical work and the existing coherent-deformation,
strain/`D_V`, and relink owners.  A coefficient impulse is only a first-hit
locator until it reenters that physical-energy gate.

No global-regularity claim is made.
