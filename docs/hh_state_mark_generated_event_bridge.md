## 1. The commuting square

At one fixed physical interaction event let

\[
T_C=g_C+b_C-n_C
\]

be the unchanged full signed hard-cell work and suppose the ordinary full-role complex Young/Christ gate holds. The preceding theorem therefore supplies a same-event role-state mark `M_C`.

The causal law has already been fixed independently:

\[
\mu_C^+=\mu_{G,C}+\mu_{B,C},
\qquad
\mu_{G,C}=(\pi_\#dW_G^+)|_C,
\qquad
\mu_{B,C}=(\pi_\#dW_B^+)|_C.
\]

There are now two operations:

1. attach `M_C` as state metadata;
2. restrict the canonical positive work law to its good sublaw.

They commute because the first operation acts on the **state coordinate** and the second acts on the **work measure**:

\[
\boxed{
(\operatorname{id},M_C)_\#(\mu_{G,C})
=
\left[(\operatorname{id},M_C)_\#(\mu_C^+)\right]\big|_G.
}
\]

Forgetting the state coordinate returns exactly

\[
\boxed{
\operatorname{pr}_\#(\operatorname{id},M_C)_\#\mu_{G,C}=\mu_{G,C}.
}
\]

No mass is created and no work is reassigned.

## 5. Shared parent state is reuse, not cloned energy

A second possible objection is that several causal parent slots can point to the same energetic parent state. The repository already has the intrinsic answer.

The dual Gaussian and Bargmann theorems turn a state mark into an **actual energy identity anchor**. Positive parent-slot weights are then pushed to those anchors. If several slots choose the same anchor, the pushforward adds their weights at one root identity:

\[
\boxed{
\sum_{p:\,a(p)=A}w_p
}
\]

rather than synthesizing several copies of the parent energy.

Thus sharing a physical state is represented by coalescence/reuse, exactly as it should be. The state-mark theorem does not create a second energy reservoir.

## 6. Fail-closed boundaries

The bridge is deliberately narrow.

- A full-state Christ failure cannot enter it.
- A mark cannot move to another hard role or another event time.
- A common-slice failure cannot be overwritten by `marking_good`.
- Bad work cannot be reopened.
- Negative work cannot enter generated mass.
- No fresh coherent Hahn law is introduced.
- No parent energy anchor is cloned when causal slots collide.

So the theorem is a deletion of a false logical dependency, not a relaxation of physical controls.
