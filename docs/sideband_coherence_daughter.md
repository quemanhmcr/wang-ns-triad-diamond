# Covariant sideband coherence and first-Duhamel daughter capacity

The purpose of this module is to prevent the orthogonal `H_1/H_3` packet forcing from becoming a new unstructured error norm.  The correct object is the **first Duhamel impulse in the common affine interaction frame**.

## 1. Banach-space variation theorem

For every absolutely continuous forcing `f:[0,T]->X` in a Banach space, let

\[
\bar f=T^{-1}\int_0^T f(t)dt.
\]

Then

\[
\int_0^T\|f-\bar f\|dt
\le {T\over2}\int_0^T\|\dot f\|dt.
\]

Indeed, write `f(t)-bar f=T^-1 int(f(t)-f(s))ds`, insert the fundamental theorem of calculus, and note that the measure of pairs `(s,t)` straddling a time `r` is `2r(T-r)<=T^2/2`.  Consequently

\[
\boxed{
\int_0^T\|f\|dt
\le
\left\|\int_0^T fdt\right\|
+{T\over2}\int_0^T\|\dot f\|dt.
}
\]

Writing `A=int||f||`, either

\[
\boxed{\|D_1(T)\|\ge A/2}
\]

for the first Duhamel daughter `D_1=int f`, or

\[
\boxed{\int_0^T\|\dot f\|dt\ge A/T.}
\]

There is no phase assumption in this statement.

## 2. Curvature interaction picture

The previous affine-curvature theorem gives

\[
\dot B+2A_{aff}B=S,
\qquad
S=L^{-1}\nabla^2(D_t^V V)[L,L].
\]

Let `Pdot=2 A_aff P` on the output index and set `Btilde=P B`.  Then

\[
\boxed{\dot{\widetilde B}=P S.}
\]

Thus common affine transport is removed before coherence is measured.  In this pulled-back grain the envelope forcing is

\[
f_3(t)=-\frac14(\operatorname{Sym}\widetilde B):H_3\,g,
\]

and

\[
{\|f_3\|_2^2\over\|g\|_2^2}
={3\over8}\|\operatorname{Sym}\widetilde B\|_F^2.
\]

Its dephasing derivative is sourced by `Sym(P S)`.  Therefore the second branch of the variation theorem is an acceleration-Hessian/source event, not an arbitrary Berry/phase error.  For resolved Navier--Stokes this source is the pulled-back form of

\[
-\nabla^3P-\nabla^2\nabla\cdot R+\nu\nabla^2\Delta V.
\]

The theorem is intentionally stated for the **first Duhamel iterate**.  If subsequent nonlinear interactions cancel a large first iterate, those cancelling terms are high--high/sideband interactions and therefore belong to the existing cross/Bellman ledger rather than to the common affine transport.

## 3. A critical `L^{3/2}` footprint

Let `g(z)=exp(-|z|^2/4)`.  The `L^2` Gaussian measure is standard normal, whereas the measure generated by `|g|^(3/2)` has variance `s=4/3`.

For `P=T:H_3`, Gaussian degree-three hypercontractivity gives

\[
\|P\|_{L^4(\gamma_s)}\le3^{3/2}\|P\|_{L^2(\gamma_s)}.
\]

Paley--Zygmund at `theta=3/11`, together with the exact variance-change lower bound, gives

\[
\boxed{
{\|Pg\|_{3/2}\over\|g\|_{3/2}}
>{1\over160}
{\|Pg\|_2\over\|g\|_2}.
}
\]

The workflow interval-certifies only the arithmetic constant `1/160`; Gaussian hypercontractivity is the analytic theorem used as input.

The same argument at degree one, plus `s_max(C)>=||C||_F/sqrt(2)` for a two-component polarization coefficient, gives the clean bound

\[
\boxed{
{\|(Cz)g\|_{3/2}\over\|g\|_{3/2}}
>{1\over16}\|C\|_F.
}
\]

Thus a coherent sideband has a nonzero footprint in the same critical Young norm that controls the transfer extremizer.
