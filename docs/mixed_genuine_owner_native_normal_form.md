# Mixed genuine-owner recurrence: native normal form after proved quotients

Status: **DRAFT THEOREM/ARCHITECTURE CANDIDATE — independent PR, not certified, not merge-ready.**

The historical mixed-owner list is larger than the actual PDE recurrence alphabet because several names are theorem manifestations of the same event. This note performs only reductions already justified by native Navier--Stokes identities.

## Proved zero-depth vocabulary

The following do not survive as primitive recursive event roots:

- intrinsic material membership rereading;
- selected-family `R_switch`;
- OO/ON/NN restriction of an already-positive service law;
- smooth or fixed-event antisymmetric `K` relink after its own physical pair law;
- hard-tail “resolved contact” as a support label.

The last point is especially important. The certified resolved-contact theorem first decomposes the actual PDE source before Hahn,

\[
dW=q\,dW+(1-q)dW,
\]

then restricts the same canonical positive cause,

\[
d\mu_{mix}=q\,d\mu,
\qquad
d\mu_{HH}=(1-q)d\mu.
\]

The mixed part has the existing signed `K+S` physics. `K` is same-event conservative donor provenance; `S` is existing strain/deformation. The HH complement is actual canonical HH work with parent upper-comparability `5M/4` and enters the certified sliding natural-window hard-shell route. Thus **resolved contact is not a fourth owner**.

Material labels are treated analogously by the candidate factorization in this PR: they restrict or annotate an already-existing physical law and do not create a second event vertex.

## Native event normal form

After these proved quotients, and after separating already-terminal transfer/reuse/sideband/global-resource/boundary events, the current genuinely recursive core reduces to the three coarse native classes

\[
\boxed{
\text{resolved source / independent service}
\quad | \quad
\text{strain / critical dissipation}
\quad | \quad
\text{actual HH / hard-tail work}.
}
\]

This is a **normal form**, not a termination theorem.

The source class is deliberately retained. The exact resolved objective-source identity and its pressure/SGS/viscous descendants provide powerful physical owner covers, but no certified theorem currently proves that arbitrary source recurrence is finite or that every source can be replaced by one of the other two event roots without additional typed event data. Removing source merely because a compiler exists would be exactly the kind of premature simplification this project forbids.

Likewise generic HH/hard-tail is retained. Signed-good generated HH has its own physical-time telescope; true upward pure-UV is first-shell; resolved-contact HH has direct natural-window reentry. None of those statements licenses declaring every generic HH event signed-good.

## Consequence for the research frontier

The mixed genuine-owner problem is therefore not “many unrelated owner labels alternate forever.” After the native quotients it is sharper:

> can an infinite pre-singular event path alternate forever among **actual source/service**, **actual strain/dissipation**, and **actual nonlinear HH/high-tail work**, while every same-event relay, material sidecar, theorem consequence, transfer/reuse cost, and absorbing boundary is treated in its correct native ledger?

Any next theorem should attack this three-root interaction directly. It must not introduce an exchange rate between source weight, `D_V`, shell mass, physical work, or time. A valid closure must come from a common local Navier--Stokes identity or from a typed transition theorem showing that one root necessarily creates a native cost/geometry in another root's ledger.

No claim is made here that this three-root recurrence is already finite. No Navier--Stokes global-regularity claim is made.
