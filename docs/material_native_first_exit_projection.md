# Native material first-exit projection

Status: **DRAFT THEOREM CANDIDATE — independent PR, not certified, not merge-ready.**

The material-service factorization and native joint-stop wrapper would be too late if a synthetic material event had already been minted upstream as a face of the smooth-SGS first-exit corridor. This note closes that topology gap.

The first-exit minimum is taken only over observables which are already physical in their native units. Pure material membership rereading, selected-family switching, and OO/ON/NN restriction of an already-positive service law are not corridor faces. They are attached after the debut.

Thus legacy labels such as `material_state_exit`, `MATERIAL_RELINK`, `NEW_COHERENT_ANCESTRY`, intrinsic membership update, or selected-family Moyal switch fail closed in the new wrapper when presented as `PhysicalPathMonitor`s.

A genuine role/probe change is **not** erased. It must appear through the already-registered physical role-interface/coefficient/work observable. That monitor participates in the first-exit set in its own units and, if it is only a coefficient obstruction, still re-enters the physical-energy gate before a causal owner is named.

If there are no native physical monitors, a material-only observation creates no first exit. If several native monitors hit simultaneously, their exact tie is preserved and material provenance cannot join it.

This theorem acts upstream of `material_native_joint_stop_projection.py`. Together they enforce the same ontology at both ends of the local corridor:

\[
\boxed{
\text{native physical debut}
\;\to\;
\text{physical routing/joint stop}
\;\to\;
\text{material provenance attached afterward}.
}
\]

It does not terminate the remaining native-owner recurrence and makes no Navier--Stokes global-regularity claim.
