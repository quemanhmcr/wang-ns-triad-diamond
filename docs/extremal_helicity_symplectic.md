# Symplectic helicity structure of the equal-parent extremal triad

A useful correction emerges only after keeping the **signed complex** helical
coupling, not merely its magnitude.  On an isosceles forward triad with
`|x|=|y|=r`, `|x+y|=1`, use the oriented triad-normal gauge.  Let the two parent
helicity indices and the child index be `s_1,s_2,s_3 in {+1,-1}`.  The
child-energy coefficient (the parent helicity difference times the Waleffe
coefficient) factorizes exactly as

\[
\boxed{
\mathcal C_{s_1s_2s_3}
=-i C(r)s_3\,\varepsilon_{s_1s_2},
\qquad
C(r)=\frac{\Delta(r,r,1)}{\sqrt2\,r},
}
\]

where

\[
\varepsilon=J=\begin{pmatrix}0&1\\-1&0\end{pmatrix}.
\]

Thus the parent helicity sector enters only through the symplectic wedge

\[
U^TJV.
\]

For every `2x2` matrix,

\[
M^TJM=(\det M)J.
\]

Consequently every common determinant-one deformation of the two parent
helicity spinors is exactly neutral:

\[
\boxed{
(MU)^TJ(MV)=U^TJV,
\qquad M\in SL(2).
}
\]

This includes the fundamental solution generated by a common trace-free
objective transverse strain, even if that strain is time dependent and
noncommuting.  Therefore **absolute opposite-helicity conversion is not, by
itself, a transfer deficit**.  This is the polarization analogue of not charging
rigid rotation or a common scale gauge.

If the two parents experience different determinant-one maps `M_1,M_2`, then

\[
\boxed{
(M_1U)^TJ(M_2V)
=U^TJ(M_1^{-1}M_2)V.
}
\]

The observable is the **relative** parent polarization deformation.  The child
helicity factor remains a separate linear factor and is not protected by this
parent symplectic cancellation.

This changes the correct 3D strain tomography.  Let

\[
D_\Pi=(S|_\Pi)^0,
\quad
D_1=(S|_{k_1^\perp})^0,
\quad
D_2=(S|_{k_2^\perp})^0,
\quad
D_3=(S|_{k_3^\perp})^0
\]

at the symmetric extremizer, where `k_3` is the child.  The transfer-relevant
quadratic observable is

\[
Q_{rel}
=\|D_\Pi\|_F^2
+\|D_1-D_2\|_F^2
+\|D_3\|_F^2.
\]

Write, in child-aligned coordinates,

\[
S=\begin{pmatrix}
a&b&x\\b&d&y\\x&y&-a-d
\end{pmatrix},
\qquad
C=\cos^2(\theta_*/2)=\frac1{4r_*^2}.
\]

Direct algebra gives the exact identity

\[
\boxed{
Q_{rel}-\frac12\|S\|_F^2
=\frac32d^2
+(1+8C-8C^2)b^2
+(7-8C)x^2+y^2.
}
\]

Arb on the certified `r_*` bracket verifies both nontrivial coefficients are
positive.  Hence

\[
\boxed{
Q_{rel}\ge\frac12\|S\|_F^2.
}
\]

Equality occurs for the one-dimensional mode `S=diag(a,0,-a)`.  The earlier
`13/20` theorem remains a valid **absolute tomography** statement, but this
`1/2` theorem uses variables that respect the exact common-`SL(2)` neutrality of
the extremal nonlinear transfer.
